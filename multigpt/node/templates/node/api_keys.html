API-Keys (MCP-Zugang)

Mit einem API-Key steuern andere Programme – z. B. n8n, Claude Desktop oder eigene Agenten – MultiGPT über den MCP-Server unter {{ request.scheme }}://{{ request.get_host }}/mcp/ (Header Authorization: Bearer <Key>). Ein Key kann nie mehr als dein Konto: Es gelten deine Rolle, Freigaben und Budgets; Kosten gehen auf dein Konto. Anleitung: Wiki „API-Keys“ und „n8n“.
