## Highlights

- **Sharing whole projects:** a project can now be shared with accounts or groups from its page ("Teilen"), with the same rights as shared chats (read, write, edit, delete). The share covers every chat in the project, including chats created later; a single chat can be kept out of it ("Nicht mit dem Projekt teilen" in the chat view). Recipients find the project under "Mit mir geteilt" on the projects page and see its name, description, instructions and chats read-only; only the owner changes, archives, deletes or shares it. Answers a recipient triggers run on the recipient's account and budget.
- **Case-insensitive login names:** "Anna", "anna" and "ANNA" are the same account at login and in `mgpt-ctl` commands. The spelling chosen at creation is kept, two accounts differing only in case are no longer possible, and the login lockout counts all spellings together.
- **Backup:** `sudo mgpt-ctl backup` writes the database (`pg_dump`), the media folder and `/etc/multi-gpt/.env` into one archive in `/var/backups/multi-gpt` (mode 0600; `--keep N`, `--dir`, `--no-media`). A daily timer ships disabled (`systemctl enable --now multi-gpt-backup.timer`). The wiki page "Backup, Update und Entfernen" describes restoring step by step.
- **Administration on the command line:** `mgpt-ctl prices list|suggest [--apply]` (prices from the LiteLLM price list), `providers list|set` (model management, memory budget, reserve, online check), `models list|set` (load priority, pinned, active), `budgets list|set` (monthly budget per role or account) and `sandbox_check`.
- **Tested package cycle:** installing 0.4.0, upgrading to 0.4.1, `remove`, `purge` and reinstalling were verified on a fresh Debian 13 with systemd (`tests/packaging/apt_cycle.sh`).
- `mgpt-ctl listusers` also works on a database with pending migrations.

## Upgrade notes

- The package runs the new migrations automatically: **accounts 0017** (login names unique regardless of case) and **chat 0055** (project shares).
- **accounts 0017** stops if two existing accounts differ only in case (e.g. `Ben` and `ben`) and names them. Rename one of them in the admin area, then run `sudo apt upgrade` (or `sudo mgpt-ctl migrate`) again.
- New dependency **postgresql-client** (for `pg_dump`). The package creates `/var/backups/multi-gpt` (owner `multi-gpt`, mode 0750).
- **Before `apt purge`:** purge deletes `/etc/multi-gpt/.env` and with it `FIELD_ENCRYPTION_KEY`; the database stays, but the stored provider API keys would be unreadable after a reinstall. Run `sudo mgpt-ctl backup` first.
- If you still have to apply the 0.4.1 settings: `USE_X_ACCEL_REDIRECT=True` in `/etc/multi-gpt/.env` for existing installations with the default `MEDIA_ROOT`.
