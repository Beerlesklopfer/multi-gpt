## Highlights

- **Own model server (Eliezer):** MultiGPT now works with Eliezer, our own model server written in Rust, as a replacement for LM Studio on the computer with the graphics card. Chat, image, speech recognition, text-to-speech, OCR and embedding models are offered with their capabilities; memory needs and free space come from Eliezer's own estimates, models are pinned and kept loaded by a watchdog, and the context length set at load time is respected before sending. A new **hub search** in the admin area (RAG overview → "Hub-Suche") shows which model variant fits into memory. The "LM Studio" interface keeps working.
- **Editing images:** attach images in "image" mode and have them changed by an image model (with a mask where the provider supports it), variations, "keep working on the last image" (threshold per chat and now per image model), custom resolutions such as wallpapers, deleting single versions of an answer or a question, and local images with FLUX.2 klein via Eliezer. Waiting for a slow local image is configurable (`IMAGE_TIMEOUT_SECONDS`, default 600 s) and keeps the connection alive.
- **Image tools without an image model:** the new tool `transform_image` crops (also to an aspect ratio such as 1:1), resizes, rotates, flips, pads, fills transparent backgrounds, converts to grayscale, adds text, builds collages and converts formats – locally, free of charge, as a new image next to the untouched original. Available to every tool-capable model for roles with the right "Create and edit images", and over MCP.
- **Voice:** a microphone next to "Send" turns speech into text (locally via Eliezer or via OpenAI) and a speaker button reads answers aloud; voice and automatic read-aloud per account, limits in the admin area, Escape stops recording and playback. Needs HTTPS in the browser.
- **Runner:** container logs per session on their own page, a `/data` volume per computer for caches and results (limit per role, default 2 GB), `multigpt-runner images list|add|remove` to allow your own work images, and `pair` asks for token and server key in the terminal. The old Python agent and the Quadlet setup are gone; only the native `multigpt-runner` remains.
- **Chat and tools:** web search derives its queries from the conversation and drops unrelated results; the tool picker is a collapsible list with search and counters; readable error details (status, kind, provider, model, request size) for the owner; messages appear top right and can be closed; switching models shows a cost hint for external models and a short introduction for local ones; today's date is part of every system prompt.
- **Costs:** price suggestions from the LiteLLM list in the admin area, prices with their own currency, a daily comparison with the providers' actual costs and the DeepSeek balance.
- **Operations:** attachments and documents are served by nginx out of the box on new installations (`X-Accel-Redirect`, see below); the version shown in the interface and admin area includes the git revision; `mgpt-ctl listusers` lists accounts with role, status and last login (no passwords or e-mail addresses); an AppArmor profile for the calculation sandbox (bubblewrap) is shipped.

## Upgrade notes

- The package runs the new database migrations automatically (accounts 0016, billing 0003–0004, chat 0047–0054, runner 0005).
- **Serving files through nginx:** the package now creates the group `multi-gpt-media`, adds `www-data` and gives it read access to the default `MEDIA_ROOT` (`/var/lib/multi-gpt/media`) – deliberately not via the group `multi-gpt`, so nginx cannot read `/etc/multi-gpt/.env`. New installations enable `USE_X_ACCEL_REDIRECT=True`. **Existing installations** can enable it in `/etc/multi-gpt/.env` and restart `multi-gpt`, but only if `MEDIA_ROOT` is the default directory; a custom `MEDIA_ROOT` (symlink, NAS share) is left untouched.
- **Runner:** runners from 0.4.0 keep working. The `/data` volume and container logs need `multigpt-runner` 0.4.1 (download it again from the page "Runner") and the new work image. The Python agent and the Quadlet unit were removed; if you still use them, pair the computer again with the native program (wiki page "Runner").
- **Image tools** are offered to roles with the right "Create and edit images" (admins and adults by default).
- **Voice** needs a speech recognition (`stt`) and a text-to-speech (`tts`) model, set in the chat settings or per account, and HTTPS for the microphone.
- **Eliezer** is optional: configure it as a provider with the "LM Studio" interface and its address; existing LM Studio providers stay as they are.
