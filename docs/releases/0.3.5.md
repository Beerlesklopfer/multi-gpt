## Highlights

- **Personal menu** in the top right with avatar: settings, profile picture, usage, API keys, family, administration, password, sign out. "My usage" and "Family" moved there from the sidebar. Upload a profile picture under Settings → Profile picture; otherwise initials are shown.
- **Parallel indexing:** several documents at once (RAG settings, "Documents in parallel", default 2), using additional worker processes (`run_worker --lane N`). Set "Parallel requests" on the OCR model accordingly. If LM Studio unloads the OCR model mid-run, the page is retried once instead of falling back to Tesseract.
- **Admins see offline MCP servers** (e.g. n8n) live in the status bar.
- If several MultiGPT installations share one LM Studio, enable "Manage models" on only one of them (relaxed in 0.3.6).
