## Highlights

- **MCP server returns tool results directly.** `run_python` returns exit status, runtime, stdout and stderr as text, generated PNG/JPEG/WebP as images, SVG and PDF as resources; `create_pdf` returns the PDF, `generate_image` the image. Results with files no longer carry `structuredContent` – `chat_id`, `message_id` and the attachments are in the last text block as JSON (n8n workflows reading `structuredContent.attachments` need to read that JSON instead).
- **SSE transport:** images are downscaled and large files are only linked (fetch with `get_file` over Streamable HTTP), because SSE clients read events up to about 1 MB.
- **Charts prefer SVG.** If code only saves SVG, MCP clients also get a PNG preview; with a PNG present the SVG is only linked. matplotlib writes SVG text as text (`svg.fonttype: none`), making files much smaller and searchable.
- **Tools on demand:** with document collections selected, the model also gets `read_document`, `list_documents` and `document_info`.
