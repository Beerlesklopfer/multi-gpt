## Highlights

- **apt repository:** MultiGPT is now installable via apt (Debian 13, amd64); see the [installation guide](https://beerlesklopfer.github.io/multi-gpt/installation/). Updates arrive with `apt upgrade`.
- **Model management (LM Studio):** indexing models (embedding, OCR, figures) are loaded for an indexing run only and unloaded two minutes after it ends (per-model switch, default on; requires "Manage models" on the provider). Disable "JIT models auto-evict" in LM Studio.
- **Anthropic prompt caching** for system prompt, tools and conversation history. Enter the cache prices on the Anthropic models so bookings reflect the savings.
- **Chat:** arrow up/down recalls previous prompts in the input field; an answer can be deleted together with its question and everything after it (shared chats: permission D). Costs stay booked.
