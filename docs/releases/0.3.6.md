## Highlights

- **Read chats via MCP:** new API key permission `chat.read` with the tools `list_chats` and `read_chat` – own chats and chats shared with the account only (never other people's chats, not even for admins). Roles allowed to ask models get the permission via migration; it must still be selected on the key.
- **API keys:** chats created by `ask` are collected in a project "API" by default (switch per key, `mgpt-ctl apikey create --no-project`).
- **Indexing:** pause and resume runs (admin, `mgpt-ctl index pause|resume`, MCP `pause_run`/`resume_run`); uploads are processed before large runs, also by idle worker lanes. Installations sharing one LM Studio only unload models they loaded themselves.
- **Shared chats:** the owner gets a notice (personal menu, `/mitteilungen/`) when a recipient deletes or archives the chat or deletes an answer.
- **Costs:** the ECB USD→EUR reference rate is fetched automatically by default (disable with `BILLING_ECB_FETCH=false`); EUR billing accounts can be switched to USD (admin action or `mgpt-ctl switch_account_to_usd`).
- **Calculations:** scipy is available in the sandbox (package about 30 MB larger compressed; sandbox memory limit should be at least 320 MB).
